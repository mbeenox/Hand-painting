futural.jhf — Hershey "Roman Simplex" single-stroke font
========================================================

`futural.jhf` in this directory is the Hershey occidental Roman Simplex
typeface in James Hurt's JHF format, vendored VERBATIM (96 glyphs, ASCII
32–127, 3.4 KB). It is also distributed under its NBS name `rowmans.jhf`;
the byte contents are identical.

Single-stroke ("engraving") fonts are the right shape for this app: every
glyph is a set of centre-line polylines, exactly the same thing the backend
emits for a traced photograph, so the hand can WRITE them with the same pen
it draws with.
